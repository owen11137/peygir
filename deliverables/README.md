# فایل‌های قابل دریافت

تمام فایل‌هایی که برای دریافت کاربر آماده می‌شوند، در این پوشه قرار می‌گیرند.

| فایل | کاربرد |
|---|---|
| [peygir-user-manual.pdf](peygir-user-manual.pdf) | راهنمای فارسی تصویری، برای مطالعه، چاپ و اشتراک‌گذاری |
| [peygir-user-manual.html](peygir-user-manual.html) | همان راهنما با فهرست، جستجو و بزرگ‌نمایی تصاویر؛ پس از دریافت، در مرورگر باز کنید |
| [peygir-users-contacts.xlsx](peygir-users-contacts.xlsx) | فایل آماده ورود کاربران با نام‌های کاربری Contacts و تیم‌های تحت نظارت |

نسخه HTML مستقل است؛ فونت‌ها و تصاویر را داخل خودش دارد و به اینترنت یا اجرای برنامه نیاز ندارد. برای دریافت فایل از گیت‌هاب، صفحه فایل را باز و **Download raw file** را انتخاب کنید؛ یا پروژه را با `git pull` به‌روز کنید.

برای ورود فایل کاربران، از «کاربران» → «ورود گروهی از Excel» استفاده کنید. ستون «تیم‌های تحت نظارت» فقط با گزینه «جایگزینی فهرست کاربران با حفظ سوابق» خوانده می‌شود. پیش از جایگزینی، کامل‌بودن فهرست را بررسی کنید.
